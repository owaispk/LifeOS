DAILY RETENTION LOOP (The Strategy)
================================================================================

MORNING (07:30)
  🔔 Voice Brief notification fires
  🎤 User hears: "Good morning. 4 tasks, 1 bill due, 2 docs expiring. Score: 78"
  → Opens app for daily briefing (ritual)

THROUGHOUT DAY
  💡 During work/commute/home, user thinks of things:
    • "Pay electricity bill Friday"
    • "Receipt for lunch" (snap photo)
    • "CNIC renewal" (voice note)
  ⊕ Tap Quick Capture FAB → choose text/voice/photo → done (< 3 sec)
  → No friction, passive engagement, app feels useful

EVENING (5–10 mins, once)
  📥 User opens Inbox, sees 5–10 pending captures
  → Tap each → classify (Task / Expense / Document / Note)
  → Sorted and saved in one batch session
  → Everything tracked, user feels in control

RESULT
  ✅ Morning ritual (07:30)
  ✅ Passive capture throughout day (< 3 sec friction)
  ✅ Batch sorting once/day (efficient, low fatigue)
  ✅ Daily habit loop formed
  ✅ More data → better ATC, forecasts, insights
  ✅ Retention jumps 40% → 65–70%
